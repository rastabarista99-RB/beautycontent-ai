# BeautyContent AI — Start Here

This package contains the first implementation blueprint for the project.

## Files

- `PROJECT_BLUEPRINT.md` — source of truth for product and engineering decisions.
- `COPILOT_PHASE_01.md` — first prompt for GitHub Copilot Agent Mode.
- `supabase/migrations/0001_initial_schema.sql` — initial database schema and RLS policies.
- `.env.example` — environment variable template.

## Local prerequisites

Use a current Node.js version compatible with the current Next.js release. The current Next.js docs list Node.js 20.9+ as the minimum.

## First action

Open an empty workspace in VS Code and use GitHub Copilot Agent Mode.

Paste the contents of `COPILOT_PHASE_01.md` into Copilot.

Do not ask Copilot to build the full application in one pass.

After Phase 01, continue with authentication, database, business onboarding, AI generation, projects, and testing as separate phases.
